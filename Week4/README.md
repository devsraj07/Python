## Use Case Diagram: Money Exchange

The `UML.png` file contains the use case diagram for the W3-A5 money exchange application.

### Description

The diagram shows how a customer do banking and use his currency to get exchange through third party exchanger application. Banking application manages by bank admin and Currency Exchange application gets managed by Exchange admin.

### Main actor

- **Customer** – Do banking and enroll in third party application to do currency exchange.
- **Bank Admin** - Manages banking application
- **Exchange Admin** - Manages Exchange application
